# Third-party references

The implementation was informed by the following public projects and platform
documentation. No source file was copied into this project.

- Akuma1tko/ChatGPT-WebView (MIT): persistent `WKWebsiteDataStore`, Mobile Safari
  User-Agent compatibility, inline media, and a code-only `WKWebView` shell.
- capnslipp/ChatGPT-iOS (MIT): keep ChatGPT-owned navigation in the WebView and
  open unrelated destinations separately.
- Apple WebKit documentation: `WKNavigationDelegate`,
  `webViewWebContentProcessDidTerminate(_:)`, `WKDownload`, and
  `WKDownloadDelegate`.
